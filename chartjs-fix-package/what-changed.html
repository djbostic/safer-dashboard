This page identifies which specific criterion (e.g. an E. coli violation, a treatment technique violation count, a risk-assessment indicator) moved alongside a status change, by comparing every field in the state's data between the day before and the day of the change. It can only see this for changes that happened after this tool started tracking — see the Failing criteria and Risk Assessment methodology for how the state defines these. Note the Failing list updates daily but the broader Risk Assessment indicators refresh quarterly, so most days will show no Risk Assessment field movement even when other things change.
